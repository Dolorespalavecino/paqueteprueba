# Suma

Esta funcion suma dos numeros positivos.

## Usage

``` r
suma(x = 2, y = 2)
```

## Arguments

- x:

  numero positivo para sumar

- y:

  otro numero positivo para sumar

## Value

vector con la suma de los sumeros positivos

## Examples

``` r
suma(3,5)
#> [1] 8
suma(28,78)
#> [1] 106
```
